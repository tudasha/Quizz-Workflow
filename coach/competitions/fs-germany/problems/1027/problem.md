# Problem 1027

The following statements are about floating-point arithmetic as defined by the IEEE 754 standard. For this question, the binary floating-point format single precision (32-bit) is assumed.

The floating-point approximation of any real number is given by the projection fl:R->F where F is any finite and discrete floating-point number system. The default rounding-direction “round ties to even” is assumed (IEEE 754-2008 4.3.3).

The floating point operators  ,-,x,/ are introduced as x y=fl(x y) for floating-point numbers x,y (similar definitions for -, x, /). These operators are lifted in order to deal with NaNs and infinities as defined by the IEEE 754 standard.

Which of the statements is CORRECT?

- A) fl(0.1)=0.1

- E) fl(0.5)-0.5
- F) The expression 0/0 evaluates to an infinity
- G) Addition of floationg-point numbers is associative, i.e., (x+y)+z=x+(y+z) for all floating-point numbers x,y,z
- H) Addition fo floating-point numbers is commutative, ie. x+y=y+x, for all floating-point numbers x,y
- I) There exist integers x,yEZ with x/=y such that fl(y)/=±∞
