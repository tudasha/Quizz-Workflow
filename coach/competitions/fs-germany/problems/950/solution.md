# Solution 950

The statement “In manual skidpad, each team has two runs, driven by one driver.” used to be part of the FS Rules until last season. For 2025, it has been removed (refer to the respective changelog entry). While each team still has two runs, the limitation that those must be driven by the same driver has been removed, thus the statement is false.
